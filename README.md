# 🏛️ GoldenEstate AI — Egyptian Real Estate Valuation
### Full-Stack Machine Learning Price Prediction App 🇪🇬

An ultra-luxurious, production-grade Machine Learning application for predicting residential property prices in Egypt.

- **Frontend:** Black & Gold Interactive UI with Area Size Tiers, Luxury Amenities, and Live Valuation Counter.
- **Backend:** High-performance FastAPI with Swagger Documentation.
- **ML Pipeline:** LightGBM, Random Forest, XGBoost & Linear Regression trained on 14,000+ Egyptian properties.
